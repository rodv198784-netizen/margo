# Margo

App de precificação e orçamentos para quem vende comida feita em casa — por V Global Ventures.

- `index.html` — página de vendas (PT/ES/EN) com calculadora rápida e plano Fundadora (Stripe)
- `app/index.html` — o app Margo (beta, dados salvos no aparelho)
- `obrigada.html` — boas-vindas após o pagamento (`?lang=pt|es|en`)
